This is a patch release. It fixes the one visible branding bug left from the 0.3.0 rename: the desktop app's sidebar still said **osu-collect**. The bundled third-party licence list now also names osu-shelf in its header. Nothing else changed.

osu-shelf is an unofficial community tool, not made, endorsed or supported by ppy (osu!) or osu!Collector.

## What changed since 0.3.0

- **Sidebar name:** the desktop app's sidebar now reads **osu-shelf** instead of osu-collect. Every 0.3.0 desktop build had the old name (AppImage, deb, Windows installer and macOS dmg).
- **Licence list:** `THIRD-PARTY-LICENSES.txt` now starts with "THIRD-PARTY LICENCES FOR THE OSU-SHELF DESKTOP APP".
- **Everything else is unchanged:** finding maps, updating collections, the mirrors, lazer imports and the terminal app work as they did in 0.3.0.

## Which file to download

| You use | Download |
|---|---|
| Windows 10/11 | `osu-shelf-desktop-0.3.1-windows-x64-setup.exe` |
| Mac with Apple Silicon (M1 or newer) | `osu-shelf-desktop-0.3.1-macos-arm64.dmg` |
| Linux, most distributions | `osu-shelf-desktop-0.3.1-linux-x64.AppImage` |
| Debian, Ubuntu and their derivatives | `osu-shelf-desktop-0.3.1-linux-amd64.deb` |
| The terminal app | the one-line installer in the [README](https://github.com/DesireThings/osu-shelf#installation), or `osu-shelf-linux-x64`, `osu-shelf-windows-x64.exe`, `osu-shelf-macos-arm64` |

The desktop app doesn't update itself, so install 0.3.1 over 0.3.0. The terminal app updates itself; its only change is the reported version.
