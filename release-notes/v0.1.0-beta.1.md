The first release of this fork of [uwuclxdy/osu-collect](https://github.com/uwuclxdy/osu-collect), and its first beta. It downloads [osu!collector](https://osucollector.com) collections from public beatmap mirrors and gets them, collections included, into osu!lazer or osu! stable.

osu-collect is an unofficial community tool, not made, endorsed or supported by ppy (osu!) or osu!Collector.

## What's in it

- **A desktop app (new):** three steps (set up, add collections, import into osu!) plus Settings, with buttons and text boxes instead of keyboard shortcuts.
- **One import for any number of collections in osu!lazer:** build one import folder, then a single pass of lazer's setup wizard brings in every map and collection.
- **The terminal app:** downloads, **find** (search maps by criteria) and **update** (fetch only what's new in collections you already have). Press <kbd>l</kbd> on the downloads tab, or run `osu-collect lazer-import`, to build the lazer import folder.
- **No osu! login:** collections never need an account. The terminal app's find through the osu! API uses an osu! API app you make on your own osu! account page.

## Opening it the first time

The apps aren't signed with a paid certificate, so Windows and macOS warn before the first start.

- **Windows:** "Windows protected your PC" → **More info** → **Run anyway**. It installs for your user only (no admin prompt) and downloads Microsoft's WebView2 if your PC doesn't have it yet.
- **macOS:** open the .dmg and drag osu-collect to Applications. The first time, macOS says it can't check the app: open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux AppImage:** make it executable (`chmod +x`) and run it. If it doesn't start, install `fuse3` (that's the package name on Arch, Debian and Ubuntu), or run it with `--appimage-extract-and-run`.

## Known limits

- **The Windows and macOS installers haven't been run on a real Windows PC or Mac yet.** They're built and checked automatically (each installer is unpacked and checked for the app and its licence list), but no one has started the app from them yet. Please [open an issue](https://github.com/DesireThings/osu-collect/issues/new) if one doesn't work.
- **macOS:** Apple Silicon only; there are no Intel Mac builds.
- **The desktop app doesn't update itself.** To update, download and install the new version over the old one. The terminal app does update itself.
- **find and update** are terminal-only for now.
- **If you also use uwuclxdy's osu-collect:** both use the same settings folder. This version deletes a saved osu!lazer login from the original, because it no longer signs in through osu!lazer's client. Your copy of the original keeps updating from its own releases.

## Checking the files

`SHA256SUMS` lists the SHA-256 of every file in this release. On Linux or macOS, in the folder with your downloads: `sha256sum -c SHA256SUMS --ignore-missing` (on macOS, `shasum -a 256 -c SHA256SUMS --ignore-missing`).
