The desktop app can now find maps and update your collections, so it does everything the terminal app does. osu-collect downloads [osu!collector](https://osucollector.com) collections from public beatmap mirrors and gets them, collections included, into osu!lazer or osu! stable. It's in early access: versions stay at 0.x until it's stable enough for 1.0.0.

osu-collect is an unofficial community tool, not made, endorsed or supported by ppy (osu!) or osu!Collector.

## What's new since 0.1.0

- **Find maps in the desktop app:** search by stars, mapper, BPM, length and more, through nzbasic's map database (no account needed) or osu! itself (with your own osu! API app, set up under **Settings**). Results sort by relevance by default, show which map sets are already **In osu!** or **Downloaded**, and can hide those with **Hide maps I already have**. Tick the ones you want and download them like a collection.
- **Update collections in the desktop app:** check the collections you downloaded before and fetch only the map sets that are new or missing. Maps you deleted on purpose are held back unless you tick them again.
- **Works with current osu! stable:** stable's newer `osu!.db` format (from early 2025) read as an empty library, so "skip maps I already have" skipped nothing and update said every map was missing. It's read correctly now, and if `osu!.db` can't be read, the app says so instead of acting as if your library were empty.
- **Finds more osu!lazer installs:** if you moved lazer's data folder to another place from lazer's settings, osu-collect now follows it. It also finds the Torii client's data folder, and when there are several installs it picks the one used most recently.
- **Smaller fixes:** a Find download's progress shows as soon as it starts, and the page stays centred in a maximised window.
- **Windows one-line installer:** no longer cuts a long `PATH` short, works when your user folder has unusual characters, and cleans up after itself. This was fixed after 0.1.0 and the installer already uses it.

If you have 0.1.0, install the desktop app over it. The terminal app offers the update by itself.

## Opening it the first time

The apps aren't signed with a paid certificate, so Windows and macOS warn before the first start.

- **Windows:** "Windows protected your PC" → **More info** → **Run anyway**. It installs for your user only (no admin prompt) and downloads Microsoft's WebView2 if your PC doesn't have it yet.
- **macOS:** open the .dmg and drag osu-collect to Applications. The first time, macOS says it can't check the app: open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux AppImage:** make it executable (`chmod +x`) and run it. If it doesn't start, install `fuse3` (that's the package name on Arch, Debian and Ubuntu), or run it with `--appimage-extract-and-run`.

## Known limits

- **The Windows and macOS builds haven't been run on a real Windows PC or Mac yet.** That covers the installers, the Windows one-line installer, and finding osu!lazer and Torii folders on those systems. They're built and checked automatically; please [open an issue](https://github.com/DesireThings/osu-collect/issues/new) if something doesn't work.
- **macOS:** Apple Silicon only; there are no Intel Mac builds.
- **The desktop app doesn't update itself.** To update, download and install the new version over the old one. The terminal app does update itself.
- **Find in the desktop app** lists map sets only: there's no per-difficulty view yet, and searches through osu! don't show download sizes.
- **Update in the desktop app** lists missing map sets by number (each links to its osu! page), not by title, and can't yet mark a set as already installed or check failed maps again.
- **If you also use uwuclxdy's osu-collect:** both use the same settings folder. This version deletes a saved osu!lazer login from the original, because it no longer signs in through osu!lazer's client. Your copy of the original keeps updating from its own releases.

## Checking the files

`SHA256SUMS` lists the SHA-256 of every file in this release. On Linux or macOS, in the folder with your downloads: `sha256sum -c SHA256SUMS --ignore-missing` (on macOS, `shasum -a 256 -c SHA256SUMS --ignore-missing`).
