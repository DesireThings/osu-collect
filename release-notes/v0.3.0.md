The app is now called **osu-shelf**. It's the same downloader for [osu!collector](https://osucollector.com) collections, with the same features; only the name, the command and the folders under the hood change. The repository was already renamed, and this release finishes the job: the terminal app is `osu-shelf`, the installers and release files use the new name, and settings and history move across by themselves on first start. It's in early access: versions stay at 0.x until it's stable enough for 1.0.0.

osu-shelf is an unofficial community tool, not made, endorsed or supported by ppy (osu!) or osu!Collector.

## What's new since 0.2.0

- **New name everywhere:** the terminal command is `osu-shelf`, the desktop app and its installers are osu-shelf, and releases are `osu-shelf-*`. Requests to osu!Collector, nzbasic and the mirrors now identify as `osu-shelf/0.3.0`.
- **Your settings move themselves:** on first start, 0.3.0 copies the old `osu-collect` settings, state files and desktop app data into new `osu-shelf` folders. It copies only, never moves or deletes, and never overwrites a newer file. The old folders stay where they are, so uwuclxdy's original keeps its own setup.
- **Your downloads stay put:** an existing `~/Downloads/osu-collect` folder keeps being used as long as there is no new `~/Downloads/osu-shelf` folder. You can rename it yourself or pick another folder in the app.
- **Updating keeps working:** 0.2.0's terminal app finds this release and updates itself, because this one release also ships identical copies under the old `osu-collect-*` file names. From 0.3.0 on, the app looks for the new names.
- **The old terminal install stays behind:** the new installer puts `osu-shelf` next to an old `osu-collect` binary instead of replacing it. Uninstall the old terminal app from **Settings → Apps → Installed apps** (Windows, listed as **osu-collect (terminal app)**) or delete `~/.local/bin/osu-collect` (Linux and macOS) once the new one works.
- **Environment overrides:** the new names are `OSU_SHELF_CONFIG` and the other `OSU_SHELF_*` variables. The old `OSU_COLLECT_*` names are still read for this release.
- **Everything else is unchanged:** finding maps, updating collections, the nine mirrors, lazer imports and the rest work as they did in 0.2.0.

## If you have 0.2.0 installed

- **Terminal app:** it offers 0.3.0 by itself and replaces its own file. To get the new binary name as well, uninstall the old one and run the one-line installer in the [README](https://github.com/DesireThings/osu-shelf#installation). Your settings are copied the first time 0.3.0 starts.
- **Desktop app:** **uninstall the 0.2.0 desktop app first** (Settings → Apps → Installed apps on Windows, drag it out of Applications on macOS, `sudo apt remove osu-collect` for the .deb). 0.3.0 uses a new internal app id, so its installer sees a new app rather than an upgrade. Then install 0.3.0; your settings are copied on first start, and an existing `~/Downloads/osu-collect` folder keeps being used.

## Opening it the first time

The apps aren't signed with a paid certificate, so Windows and macOS warn before the first start.

- **Windows:** "Windows protected your PC" → **More info** → **Run anyway**. It installs for your user only (no admin prompt) and downloads Microsoft's WebView2 if your PC doesn't have it yet.
- **macOS:** open the .dmg and drag osu-shelf to Applications. The first time, macOS says it can't check the app: open **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux AppImage:** make it executable (`chmod +x`) and run it. If it doesn't start, install `fuse3` (that's the package name on Arch, Debian and Ubuntu), or run it with `--appimage-extract-and-run`.

## Known limits

- **The Windows and macOS builds haven't been run on a real Windows PC or Mac yet.** That covers the installers, the Windows one-line installer, and finding osu!lazer and Torii folders on those systems. They're built and checked automatically; please [open an issue](https://github.com/DesireThings/osu-shelf/issues/new) if something doesn't work.
- **macOS:** Apple Silicon only; there are no Intel Mac builds.
- **The desktop app doesn't update itself.** To update, download and install the new version over the old one. The terminal app does update itself.
- **Find in the desktop app** lists map sets only: there's no per-difficulty view yet, and searches through osu! don't show download sizes.
- **Update in the desktop app** lists missing map sets by number (each links to its osu! page), not by title, and can't yet mark a set as already installed or check failed maps again.
- **If you also use uwuclxdy's osu-collect:** since this release the two keep separate settings, and the original's files are left alone. An existing `~/Downloads/osu-collect` folder keeps being used for downloads; rename it or pick another folder to keep the two apart. A saved osu!lazer login is dropped from the copy, because osu-shelf no longer signs in through osu!lazer's client. Your copy of the original keeps updating from its own releases.

## Checking the files

`SHA256SUMS` lists the SHA-256 of every file in this release. On Linux or macOS, in the folder with your downloads: `sha256sum -c SHA256SUMS --ignore-missing` (on macOS, `shasum -a 256 -c SHA256SUMS --ignore-missing`).
