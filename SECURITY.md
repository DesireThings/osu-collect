# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately
instead, through [GitHub's private vulnerability reporting](https://github.com/DesireThings/osu-collect/security/advisories/new)
(the **Report a vulnerability** button on the repository's Security tab).

Say what you found, how to reproduce it, and which version you used
(`osu-collect --version` for the terminal app; for the desktop app, the
version in the installer's file name).

This is a one-person hobby project, so there's no guaranteed response time,
but reports are read and answered.

## Supported versions

Only the newest release gets fixes. osu-collect is in early access (version
0.x), so there are no older release lines.

## Scope

In scope: this repository's code, its install scripts (`install.sh`,
`install.bat`), its release workflow and the files attached to its releases.

Out of scope: the download mirrors, osu!Collector, and osu! itself. Report
problems with those to the people who run them.
