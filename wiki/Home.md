# osu-collect wiki

Full reference for [osu-collect](https://github.com/DesireThings/osu-collect#readme), a downloader for osu!collector beatmap collections, with a desktop app and a terminal app. It's an unofficial community tool, not made, endorsed or supported by ppy (osu!) or osu!Collector.

New here? Start with [Installation](Installation), then [Desktop app](Desktop-App) or, for the terminal app, [Usage](Usage).

| Page | What it covers |
|---|---|
| [Installation](Installation) | Install methods per OS, self-updating, uninstalling, building from source |
| [Desktop app](Desktop-App) | The window: set up, add and download collections, import into osu!, settings |
| [Usage](Usage) | Terminal app: first download, the get maps form, the downloads tab, retrying failures |
| [Finding maps](Finding-Maps) | The find source: criteria, filter syntax, backend routing |
| [Updating collections](Updating-Collections) | Re-checking downloaded collections, marking maps installed |
| [Importing into osu!](Importing-into-osu) | Getting the maps + `collection.db` into lazer or stable |
| [Keybindings](Keybindings) | Every key, including the vim keymap |
| [Configuration](Configuration) | `config.toml` locations, every key with its default |
| [Mirrors](Mirrors) | Built-in mirror list, rate-limit handling, custom mirrors |
